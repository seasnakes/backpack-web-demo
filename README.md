# 背包自走棋网页原型

原创的背包自走棋网页原型（纯前端单文件实现，非任何游戏的官方版或原版移植）。

## 在线访问

通过 GitHub Pages 打开部署链接即可游玩，无需安装。

## 操作方法

- 在页面内按提示用鼠标点击 / 拖拽进行背包整理、合成与战斗操作，具体规则以页面内说明为准。
- 支持现代浏览器（Chrome / Edge / Firefox / Safari）。

## 本地打开方式

直接用浏览器打开 `index.html`，或在目录内起静态服务：

```bash
python3 -m http.server 8000
# 然后访问 http://localhost:8000
```

## 文件

- `index.html`：完整游戏原型（HTML/CSS/JS 合一）
